Sigue estos pasos en orden para levantar todo el proyecto en local:

1. LEVANTAR BASE DE DATOS (Docker)
   ---------------------------------
   Abre una terminal en la raíz del proyecto y ejecuta:
   > docker-compose up -d
   (Levanta PostgreSQL 16 con la extensión vectorial pgvector en el puerto 5432).

2. ENCENDER EL BACKEND (FastAPI + LangGraph + Visión IA + Bot Telegram + Gmail)
   ---------------------------------
   Abre una terminal en la carpeta 'backend', activa el entorno virtual y arranca:
   > cd backend
   > venv\Scripts\activate
   > uvicorn main:app --reload --host 0.0.0.0 --port 8000

   NOTA: Al encender el backend se ejecutan AUTOMÁTICAMENTE:
   - La creación de todas las tablas y la extensión pgvector.
   - La creación del Tenant 1 y los usuarios iniciales ('admin', 'auditor', 'user', 'service').
   - La migración automática de cifrado en reposo (Ley 1581 - AES-128 + RSA-2048).
   - El hilo lector de correos de Gmail (IMAP cada 60s) y el Bot de Telegram (@Indicion8n_bot).

3. ENCENDER EL FRONTEND (React / Vite)
   ---------------------------------
   Abre una NUEVA terminal en la carpeta 'frontend':
   > cd frontend
   > npm run dev
   (Disponible en http://localhost:5173).
