===================================================
GUÍA RÁPIDA: ENCENDIDO Y USO CORRECTO DE INDICIO
===================================================

Sigue estos pasos en orden para levantar todo el proyecto correctamente:

1. LEVANTAR CONTENEDORES (Docker)
   ---------------------------------
   Abre una terminal en la raíz del proyecto y ejecuta:
   > docker-compose up -d
   (Esto levanta la Base de Datos PostgreSQL y el servidor de automatización n8n).

2. CONFIGURACIÓN INICIAL DE USUARIOS Y TABLAS (Solo la primera vez o tras actualizaciones)
   ---------------------------------
   Abre una terminal, entra a la carpeta 'backend', activa el entorno virtual y ejecuta los scripts:
   > cd backend
   > venv\Scripts\activate
   > python migration_vacancies.py (Crea la tabla de vacantes y actualiza el esquema RAG de Hojas de Vida)
   > python create_admin.py        (Crea el admin y auditor con roles asignados: 'admin' y 'auditor')
   > python create_n8n_user.py     (Crea el usuario de servicio 'n8n.service@gmail.com' con rol 'service')

3. ENCENDER EL BACKEND (FastAPI / IA / Criptografía)
   ---------------------------------
   En la misma terminal del backend, con el entorno virtual activado:
   > uvicorn main:app --reload --host 0.0.0.0 --port 8000
   (El backend quedará escuchando en el puerto 8000 con cifrado de datos sensibles y RBAC activado).

4. ENCENDER EL FRONTEND (React / Vite)
   ---------------------------------
   Abre una NUEVA terminal, entra a la carpeta 'frontend' y levanta el entorno:
   > cd frontend
   > npm run dev
   (El frontend estará disponible en http://localhost:5173).

5. AUTOMATIZACIONES Y CORREOS (n8n)
   ---------------------------------
   Entra a http://localhost:5678 en tu navegador.
   Asegúrate de que los Workflows de "Ingesta" y "Notificaciones" estén activados (en ON).
   Esto permitirá que el sistema reciba correos automáticamente y responda al terminar.

   ---------------------------------

   A. Modo Administrador (Acceso total):
      Email: indicio.admin@gmail.com

      Permisos: Cargar, eliminar, editar vacantes, carpetas y ver logs de auditoría.

   B. Modo Auditor (Solo Lectura y Verificación):

7. ASISTENTE RAG POR TELEGRAM (@Indicion8n_bot)
   ---------------------------------
   Para consultar tus documentos desde Telegram desde cualquier celular:
   > cd backend
   > venv\Scripts\activate
   > python telegram_bot_service.py
   (El bot responderá a tus preguntas en tiempo real citando las fuentes).
